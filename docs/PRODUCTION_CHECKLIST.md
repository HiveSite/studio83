# Produkcijska checklista

## P0 - mora biti završeno prije objave

- [ ] Potvrđen kanonski domen sa ili bez `www`
- [ ] Kontakt Apps Script testiran sa produkcijskog domena
- [ ] Potvrđeno da kontakt endpoint vraća `{ "ok": true }`
- [ ] GTM Preview testiran
- [ ] Provjeren mogući dupli GA4 `page_view`
- [ ] `generate_lead` dolazi samo jednom
- [ ] Jobs endpoint vraća aktivne poslove
- [ ] Prijava kandidata stiže u postojeći sistem
- [ ] Objava angažmana stiže na odobrenje
- [ ] Pravno pregledane stranice Privatnost, Kolačići i Uslovi
- [ ] Potvrđena dozvola za case study nazive i brojke
- [ ] Provjeren email `sindikatevents@gmail.com`
- [ ] `npm run check` prolazi bez greške

## P1 - odmah nakon objave

- [ ] Test mobilnog menija na iOS i Android uređaju
- [ ] Test kontakt forme na mobilnoj mreži
- [ ] Test svih glavnih CTA dugmadi
- [ ] Provjera Search Console URL Inspection
- [ ] Slanje `/sitemap.xml`
- [ ] Provjera 301 redirecta sa starih URL-ova
- [ ] Provjera 404 stranice
- [ ] Provjera Instagram i ImaPosla linkova
- [ ] Provjera cookie izbora Accept i Reject
- [ ] Provjera GA4 DebugView sa odbijenim i prihvaćenim consentom

## P2 - kvalitet i prodaja

- [ ] Dodati stvarne fotografije tima i aktivacija
- [ ] Dodati izjave klijenata sa dozvolom
- [ ] Dodati još najmanje dva detaljna case study projekta
- [ ] Potvrditi konačne cjenovne okvire
- [ ] Uvesti datum objave i izmjene blog tekstova
- [ ] Definisati internu osobu koja odgovara na leadove
- [ ] Definisati maksimalno vrijeme odgovora na kontakt formu
- [ ] Povezati leadove sa CRM-om ako volumen poraste

## Mjesečna provjera

- [ ] Kontakt forma radi
- [ ] Jobs feed radi
- [ ] Blog feed radi
- [ ] Nema 404 rastova
- [ ] GA4 key events rade
- [ ] Najvažnije stranice zadržavaju indeksaciju
- [ ] Cijene i ponuda su ažurne
- [ ] Case brojke i javne tvrdnje su i dalje tačne
